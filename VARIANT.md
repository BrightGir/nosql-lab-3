# Вариант №7809

Продолжение лабораторных №1 и №2 с сохранением CRUD API и существующих хранилищ.

- Новая система: ScyllaDB, минимум 3 узла, replication factor 3.
- События: выполнение бизнес-операций.
- Обязательный запрос: события с заданным результатом за период.
- Временной бакет: один день.
- Согласованность: запись ONE, чтение QUORUM.
- Отказ: остановка одного узла-реплики.
- Внутренний механизм: образование и удаление tombstones.
- Минимум три денормализованные таблицы под запросы, без фильтрации.
- Сортировка, пагинация, нагрузочный эксперимент: throughput, mean, p95.
